# Contributing

Report your tested configuration and a reproducible scene or sequence of actions. Include whether the Qt canvas is active, whether the native canvas is hidden, and whether the issue affects rendering, copying, or image navigation.

Use an empty scene or a small scene you can share. Remove personal paths, account identifiers and license data from logs. Do not upload proprietary application binaries.

Changes to internal Qt/MtoA integration need interactive testing in Maya. Syntax and installer tests alone do not prove graphics compatibility. Please document render dimensions, native image scale, high-DPI behavior and restart/reopen tests.
